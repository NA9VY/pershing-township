# Pershing Township Website

Official website for **Pershing Township, Jackson County, Indiana**.

## Pages
- `index.html` — Home
- `park.html` — Park / Shelter House / Playground / Field
- `gym.html` — Gym / Community Center
- `cemeteries.html` — Cemeteries
- `assistance.html` — Township Assistance
- `rentals.html` — Rentals
- `notices.html` — Notices / Meeting Minutes / Disclosures

## Hosting
This is a simple static site intended for GitHub Pages (or later an official domain such as pershingtownshipin.gov).

## Development
Open any `.html` file in a browser to preview. Shared styles are in `styles.css`.
